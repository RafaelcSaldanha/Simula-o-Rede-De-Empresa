# Simula-o-Rede-De-Empresa

# 🌐 Projeto — Infraestrutura de Rede Corporativa

Este projeto consiste na criação e configuração de uma infraestrutura de rede corporativa utilizando o **Cisco Packet Tracer**, simulando o funcionamento de uma empresa com diferentes setores e necessidades de comunicação.

A rede foi estruturada utilizando **VLANs** para segmentar os setores da empresa, além da implementação de **endereçamento IPv4**, subnetting e comunicação entre diferentes redes.

Também foram configurados recursos importantes de infraestrutura e segurança, como **DHCP**, **NAT/PAT**, **ACLs**, redes **Wi-Fi** e políticas de controle de acesso entre os setores. O projeto inclui ainda a comunicação entre diferentes pontos da infraestrutura, simulando um ambiente corporativo mais próximo de uma rede real.

## 🛠️ Tecnologias e conceitos aplicados

* Cisco Packet Tracer
* VLANs e segmentação de redes
* IPv4
* Subnetting
* Router-on-a-Stick
* DHCP
* NAT/PAT
* ACLs
* Controle de acesso entre redes
* Redes Wi-Fi
* Roteamento entre VLANs
* Infraestrutura de rede corporativa

🎯 **Objetivo:** desenvolver uma infraestrutura de rede organizada, segmentada e segura, aplicando na prática conceitos fundamentais de redes de computadores e infraestrutura.
